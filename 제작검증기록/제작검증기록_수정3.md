## 수정 기록

### 수정 기록 1
- 발견한 문제: 웹페이지 첫 접속 시 아무런 안내 없이 바로 딱딱한 표가 나타나 삭막하고, 사용자가 어떤 작업부터 해야 할지 직관적이지 않음.
- AI에게 전달한 요청: 처음에 슬라이드 스위치가 나오고, 드래그해서 켜면 '실험 시작~!' 하는 아기 목소리 효과음과 함께 '치이카와 우사기' 캐릭터(참고 GIF 제공)가 등장했다가 2초 뒤 축소되며 우측 하단으로 이동하는 인트로 화면 추가를 요청함.
- 수정 후 테스트 결과: AI가 초기 요청한 아기 목소리 대신 엉뚱한 '띠용' 효과음을 넣어 '짜라란(샤라락)' 효과음으로 다시 명령하여 수정함. 또한 저작권 문제로 우사기 캐릭터 사용이 불가능하다고 하여, AI가 직접 코드로 그린 오리지널 토끼(SVG) 이모티콘으로 대체하는 것을 수용함. 최종 테스트 결과, 스위치를 드래그하면 샤라락 소리와 함께 토끼가 등장하고 2초 뒤 우측 하단으로 스무스하게 이동하며 계산기가 정상 활성화됨. 기존 계산 기능도 망가지지 않음.
- 수정 이유: 페이지의 첫인상을 부드럽게 만들고 시각적/청각적 흥미를 유발하여 딱딱한 실험 계산기에 친근함을 더하기 위함. 저작권 문제를 안전하게 회피하면서도 원래 의도했던 사용자 경험(UX) 개선이라는 목적을 성공적으로 달성함.

### 수정 기록 2
- 발견한 문제: 화학 시약명(예: Dichloromethane 등)이 길고 복잡한 경우가 많은데, 매번 끝까지 직접 타이핑해야 해서 번거롭고 오타가 발생하기 쉬움.
- AI에게 전달한 요청: 서버나 외부 DB 없이 자주 쓰이는 화학 시약 이름들을 코드 내부에 저장하고, 시약명 입력 칸에 글자를 칠 때 연관 검색어(자동완성 후보)가 드롭다운으로 나타나 클릭 시 자동 입력되는 기능 추가를 요청함 (기존 기능 유지).
- 수정 후 테스트 결과: 시약명 칸에 텍스트를 입력하면 미리 하드코딩된 시약 목록을 바탕으로 드롭다운 메뉴가 정상적으로 표시됨. 키보드 방향키나 마우스로 항목을 선택하면 입력창에 정확히 채워지며, '반응물 추가'로 생성된 새 행에서도 자동완성 기능이 완벽하게 동작함. 기존의 계산이나 애니메이션 기능도 깨지지 않음.
- 수정 이유: 자주 사용하는 시약 이름을 매번 끝까지 타이핑하는 것은 사용자에게 피로감을 유발하며, 오타로 인해 이후 다운로드한 CSV 데이터의 신뢰성이 떨어지는 문제를 방지하기 위함.

### 수정 기록 3
- 발견한 문제: 시약명은 자동완성되지만 가장 번거로운 '분자량(MW)'은 여전히 사용자가 직접 찾아서 수기로 입력해야 하므로 번거롭고 오타(실험 실패의 원인)가 발생할 위험이 큼.
- AI에게 전달한 요청: 기존 자동완성 목록(배열)에 분자량(MW) 수치를 추가하고, 드롭다운 목록에 분자량도 함께 표시해 달라고 요청함. 또한 목록에서 시약을 선택하면 시약명 칸과 분자량 칸이 동시에 자동으로 채워지도록 기능 연동을 요청함.
- 수정 후 테스트 결과: 시약명 검색 시 드롭다운 우측에 분자량이 함께 예쁘게 표시됨. 항목을 클릭하면 시약명 칸과 분자량 칸에 값이 즉시 채워짐. 이후 당량(eq)만 입력하면 투입 질량이 즉시 자동 계산되어 매우 빠르고 정확해짐.
- 수정 이유: 분자량은 각 화학 물질마다 정해진 고유 수치이므로 매번 수기로 입력하게 두면 시간이 오래 걸릴 뿐만 아니라, 오타 시 전체 실험 비율이 완전히 망가지는 치명적인 결과를 낳기 때문임.
