## 수정 기록

### 수정 기록 1
- 발견한 문제: 웹페이지 첫 접속 시 아무런 안내 없이 바로 딱딱한 표가 나타나 삭막하고, 사용자가 어떤 작업부터 해야 할지 직관적이지 않음.
- AI에게 전달한 요청: 처음에 슬라이드 스위치가 나오고, 드래그해서 켜면 토끼 마스코트가 등장했다가 축소되며 이동하는 인트로 화면 추가를 요청함.
- 수정 후 테스트 결과: 스위치를 드래그하면 샤라락 소리와 함께 토끼가 등장하고 2초 뒤 우측 하단으로 부드럽게 이동하며 계산기가 활성화됨.
- 수정 이유: 페이지 첫인상을 부드럽게 만들고 시각적/청각적 흥미를 유발하여 친근함을 더하기 위함.

### 수정 기록 2
- 발견한 문제: 화학 시약명이 길고 복잡한 경우가 많은데, 매번 끝까지 직접 타이핑해야 해서 번거롭고 오타가 발생하기 쉬움.
- AI에게 전달한 요청: 자주 쓰이는 화학 시약 이름들을 코드 내부에 저장하고, 입력 시 연관 검색어(자동완성) 드롭다운을 띄워주는 기능 추가.
- 수정 후 테스트 결과: 시약명 입력 시 자동완성 드롭다운이 잘 표시되며, 클릭 시 새 행에서도 정확히 입력됨.
- 수정 이유: 사용자의 타이핑 피로감을 줄이고 결과 데이터(CSV)의 오타를 방지하기 위함.

### 수정 기록 3
- 발견한 문제: 가장 번거로운 '분자량(MW)'은 여전히 수기로 입력해야 해서 오타 위험이 존재함.
- AI에게 전달한 요청: 자동완성 목록에 분자량을 추가하고, 시약을 선택하면 이름과 분자량 칸이 동시에 채워지도록 연동.
- 수정 후 테스트 결과: 드롭다운에서 시약 선택 시 이름과 분자량이 동시에 입력되며, 바로 투입 질량이 계산됨.
- 수정 이유: 분자량 수기 입력 시간을 단축하고, 치명적인 계산 오타를 방지하기 위함.

## 사용자 테스트
- 테스트 참여자와 요청한 작업: 동료에게 당량 계산기 웹사이트 접속 후 벤조산과 에탄올 등의 당량을 계산해 볼 것을 요청함.
- 사용자의 행동과 질문: 웹사이트에 들어가자마자 인트로 스위치를 오른쪽으로 직관적으로 드래그하여 열고, 기준 시약과 반응 시약 추가 시 자동완성 기능을 능숙하게 활용함.
- 받은 피드백: 
  1. 연관검색어 기능에서 마우스 휠 스크롤이 매끄럽게 작동하지 않음.
  2. 표의 '행 삭제' 버튼이 좁은 화면에서 줄바꿈되어 안 예쁨 (한 줄로 보였으면 함).
  3. 오른쪽 아래로 이동한 귀여운 토끼를 클릭하면 토끼가 실험복으로 갈아입으며 '메모장'이 열렸으면 좋겠음.
  4. 실험을 여러 개 할 수 있도록 '표 추가' 버튼을 만들어서 기준 시약을 여러 개 독립적으로 작성할 수 있었으면 좋겠음.
- 반영 내용과 결과: 4가지 피드백을 모두 반영함. CSS를 수정하여 스크롤 간섭 및 삭제 버튼 줄바꿈을 해결하고, 우측 하단의 토끼 클릭 시 로컬 스토리지가 연동되는 '실험 메모장' 팝업을 구현함. 또한, '새 실험 표 추가' 버튼을 도입하여 여러 개의 독립된 계산 표를 한 화면에 띄우고 데이터가 개별적으로 연동·저장되도록 구조를 대폭 확장함.
